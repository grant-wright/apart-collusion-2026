# apart-collusion-2026

Code and data for **"Nothing to collude for: told-to-collude LLM agents gain nothing over a matched innocent
pair in five Colosseum environments"** -- an entry to the Apart Research AI Collusion Research Sprint
(23-25 Oct 2026), by Grant Wright.

**Status: being populated.** The environment wrappers, scripts, run configs, run outputs and the experiment
journal (cited in the report as [J n]) will be added here by **28 Oct 2026 (NZDT, UTC+13)**. Until then they
are available from the author on request.

Built on Colosseum (Nakamura et al., 2026, `github.com/umass-ai-safety/colosseum`) and the
poseidon-research sprint starter bundle (`github.com/poseidon-research/collusion_hackathon`), which are not
redistributed here.
